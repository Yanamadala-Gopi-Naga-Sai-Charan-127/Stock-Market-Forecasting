# 📈 Stock Market Forecasting and Financial Trend Analysis System

A web-based Stock Market Forecasting and Financial Trend Analysis System that helps users analyze stock market data, visualize financial trends, and predict future stock prices using Python-based forecasting techniques. The application provides an interactive dashboard where users can search stock symbols, view historical price movements, analyze trends, and receive AI-based predictions with risk assessment.

---

## 🚀 Features

- 📊 Real-time stock market analysis
- 📈 Financial trend visualization using interactive charts
- 🤖 AI-based stock price prediction
- ⚠️ Risk level analysis (Low, Medium, High)
- 💹 Buy/Sell/Wait recommendation system
- ⭐ Watchlist management
- 🔍 Search stocks by ticker symbol
- 📱 Responsive and user-friendly interface
- 💾 SQLite database for data storage

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/Yanamadala-Gopi-Naga-Sai-Charan-127/Stock-Market-Forecasting.git
```

### Navigate to the Project

```bash
cd Stock-Market-Forecasting
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Project

```bash
python manage.py runserver
```

or

```bash
python app.py
```
